Luravia

A modern ecommerce storefront built with Next.js 16, TypeScript, Tailwind CSS, Framer Motion, and Context API.

Features:
- Responsive design
- Dark / light theme support
- Shopping cart management
- Product catalog
- Category browsing
- Modern component architecture

Tech Stack:
- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Context API
- Lucide Icons
